# Arquivo do site antigo da raiz

Este diretorio preserva o backend MVP e os arquivos CSS/JavaScript que ficavam
na raiz antes da reorganizacao. A versao ativa foi movida para a raiz do
repositorio; nao desenvolva funcionalidades novas neste arquivo historico.

O banco SQLite e os uploads locais antigos foram mantidos separadamente em
`old/legacy-local/` apenas neste computador e sao excluidos pelo `.gitignore`.
Nao envie esses dados para o GitHub.
