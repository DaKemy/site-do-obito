# Arquivo de versões antigas

`legacy-root/` preserva o código do site e do backend que ficavam na raiz antes
da promoção da versão 0.0.2. Use a raiz do repositório para qualquer alteração
nova.

Arquivos locais privados, como `.env`, o banco SQLite e uploads, não fazem parte
deste arquivo público. A cópia local de segurança fica em `legacy-local/` e é
excluída do Git pelo `.gitignore`.
