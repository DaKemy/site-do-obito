# Versões arquivadas

Esta pasta contém as cópias históricas do projeto:

- `0.0.0`: primeira versão preservada.
- `0.0.1`: versão desenvolvida manualmente pela colaboradora.
- `0.0.11`: versão anterior da aplicação.
- `site-obito-v0.0.1-original.rar`: compactado original mantido como referência.

A versão principal e o desenvolvimento ativo estão na raiz do repositório.
As cópias arquivadas não recebem alterações de funcionalidades. Elas foram
mantidas para consulta e comparação.

Configurações privadas, bancos de dados e arquivos enviados por clientes não
fazem parte do arquivo público. Cópias locais desses dados não devem ser
compartilhadas nem adicionadas ao Git.
